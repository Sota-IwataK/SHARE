## Unity package restore

This project uses Unity 2022.3 LTS and depends on ROS TCP Connector through Unity Package Manager:

```json
"com.unity.robotics.ros-tcp-connector": "https://github.com/Unity-Technologies/ROS-TCP-Connector.git?path=/com.unity.robotics.ros-tcp-connector#v0.7.1"
```

Because this is a Git URL dependency, Unity must be able to find `git.exe` from the environment used to launch Unity Hub and the Unity Editor. On Windows, add Git for Windows to the system `Path`, for example:

```text
C:\Program Files\Git\cmd
```

After changing `Path`, fully close Unity Hub and Unity Editor, then reopen the project so Package Manager can resolve the dependency again.

If Package Manager keeps stale data, close Unity and delete the local generated package cache:

```text
Library\PackageCache
```

`Library` is generated by Unity and is ignored by git in this repository. Unity will recreate it on the next project open.
